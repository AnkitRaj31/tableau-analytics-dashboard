# Tableau Analytics Dashboard

An interactive Tableau project that explores retail sales performance, profitability, returns, product trends, and geographic performance using the Superstore dataset. The workbook also includes analysis built with the Netflix Titles dataset.

## Project File

- `tableau-analytics-dashboard.twbx` — Packaged Tableau workbook containing the dashboards and data extracts.

## Dashboard Highlights

- Total sales, profit margin, and return-rate metrics
- Sales trend analysis over time
- Sales by sub-category and top 50 products by sales
- Geographic analysis of sales performance
- Interactive dashboard views for retail and entertainment data

## Tools Used

- Tableau public
- Tableau calculations and dashboard design
- Data visualization and interactive filtering
- Superstore and Netflix Titles datasets

## How to Open

1. Download `tableau-analytics-dashboard.twbx`.
2. Open the file using Tableau Public.
3. The packaged workbook includes its data extracts, so no separate data source setup should be required.
